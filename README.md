# ASCII Sea

A beautifully animated, realistic calm sea built purely with ASCII characters on an HTML Canvas. It uses layered sine waves to generate organic, flowing water motions mapped to characters of different colors and stroke densities.

## How to host on GitHub Pages:
1. Create a new repository on GitHub.
2. Upload all the files from this folder (`index.html`, `style.css`, `script.js`) directly to the root of the repository.
3. Go to your repository's **Settings** tab.
4. On the left sidebar, click on **Pages**.
5. Under "Source", select the `main` (or `master`) branch and save.
6. Your ASCII sea will be live at `https://[your-username].github.io/[repository-name]`.
